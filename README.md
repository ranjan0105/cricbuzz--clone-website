# Cricbuzz Clone Website

This project is a **Cricbuzz website clone** developed to recreate the look, feel, and basic functionality of a modern cricket-focused sports website. The project is designed as a front-end development practice project and focuses on building a clean, responsive, and user-friendly interface for displaying cricket-related information.

## 📌 About the Project

The **Cricbuzz Clone Website** is inspired by the popular Cricbuzz cricket platform. It provides a similar layout and structure for presenting cricket news, match information, scores, teams, players, and other cricket-related content.

The main purpose of this project is to practice and demonstrate front-end web development skills, including website layout design, responsive UI development, navigation, reusable components, and organizing a web project into a structured codebase.

## 🚀 Features

* 🏏 Cricket-focused homepage
* 📊 Match score and match information sections
* 📰 Cricket news and updates section
* 👥 Teams and players sections
* 🗓️ Match schedule layout
* 🔴 Live/upcoming/recent match sections
* 📱 Responsive design for different screen sizes
* 🧭 Navigation menu for easy access to different sections
* 🎨 User-friendly and clean interface
* 🔄 Reusable UI components
* 💻 Desktop, tablet, and mobile-friendly layout
